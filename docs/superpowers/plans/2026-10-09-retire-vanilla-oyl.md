# Cutover part 2 — Retire `apps/vanilla-oyl` — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [x]`) syntax for tracking.

**Goal:** Port the e2e coverage only vanilla had (a11y, connection, Google OAuth) to the stencil projects — closing the two small stencil gaps they expose (route announcement + focus-to-heading in `oyl-router`, inline URL validation on Status) — then delete `apps/vanilla-oyl` and everything that existed only for it, and rewrite the operator docs.

The e2e backend's `APP_URL` becomes the stencil origin. `pnpm dev` and compose point at the Stencil dev server. ui-oyl's themes become the source.

**Tech Stack:** as before.

**Spec:** `docs/superpowers/specs/2026-10-09-retire-vanilla-oyl-design.md`
